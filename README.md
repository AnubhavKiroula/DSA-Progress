# 🧠 DSA-Progress

> Real-time sync of my LeetCode solutions (C++, Python, SQL) with structured problem statements, constraints, and latest accepted code — synced automatically via **LeetHub**.

---

## 📌 Introduction

This repository tracks my Data Structures & Algorithms journey by syncing accepted LeetCode submissions into organized folders in real-time. Each problem folder contains:

- A `README.md` with the problem title, difficulty, full statement, constraints, and examples.
- A solution file with the accepted code and performance statistics (runtime & memory).

---

## 💻 Languages Supported

| Language | Extension | Folder |
|---|---|---|
| C++ | `.cpp` | `problems/<slug>/` |
| Python | `.py` | `problems/<slug>/` |
| SQL | `.sql` | `problems/<slug>/` |
